# snake-game

retro snake in one single html file. no libs, no assets, no bullshit.

## play

open `index.html` in any browser. that's it.

## controls

| key | does |
|---|---|
| arrows / wasd | move |
| space | pause |
| enter | restart |
| m | mute |

touch works too, swipe to steer.

## stuff inside

- speeds up every 50 points
- best score saved in the browser
- beeps made with webaudio, zero audio files
